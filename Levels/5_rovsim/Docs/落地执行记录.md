# ROVSim 落地执行记录

日期：2026-05-04

## 已落地

- 主界面从底部挤压式图表布局改为工作台布局：顶部工具栏、左侧资源路径、中央 Tab、右侧 Inspector、底部状态栏。
- 图表移入“图表分析”页，继续使用 `ui_modules/TauRealtimeChart` 与 `addons/tau-plot`。
- 新增机器、推进器模板、记录、图表布局的 JSON 保存/加载服务。
- 新增 CSV 导出服务。
- 新增推进器模板、推进器实例、机器配置、图表布局、项目配置模型。
- 新增记录帧中的 `ForceSnapshot`，记录推进器力、浮力、重力、阻力、合力、力矩。
- 新增 3D 力矢量渲染层和固定图例。
- 新增推进器模板参数面板，可编辑正/反推力、直径、长度并应用到当前推进器。
- 新增整机装配核心参数面板，可编辑质量、排水体积、重心高度、浮心高度。
- 新增记录加载后的回放时间轴，可按帧驱动 3D 机体与力矢量。
- 内置机器与推进器预设迁移为 JSON 文件，脚本预设库优先读取 JSON。

## 已知环境噪音

- Godot 在当前 Windows 沙箱启动时输出 `Failed to read the root certificate store`。
- Godot 在退出时输出一次 shader cache `Condition "f.is_null()" is true`。
- 以上两项未指向项目脚本、场景或资源加载错误。
