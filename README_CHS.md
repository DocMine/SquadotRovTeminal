# ROV Runtime Builder & Simulator
[English Version](README.md)

一个基于 **Godot Engine 4.6** 的水下机器人（ROV）**运行时拼装 + 仿真**项目。

本项目的目标不是复刻 Godot 编辑器，而是在**程序运行时**提供一个**受限、可维护、可交付给客户的拼装系统**：

* 使用组件（Parts）拼装机器人
* 在运行时通过 UI 调整零件的位置、朝向与参数
* 一键切换到仿真模式，验证设计效果

项目在设计上参考了《围攻（Besiege）》一类游戏的拼装体验，但整体定位更偏向**工程仿真、教学与方案验证工具**。

---

## ✨ 核心特性

* 🧩 **运行时拼装（Runtime Builder）**
  无需 Godot 编辑器，用户可在程序运行时完成 ROV 的拼装与配置。

* ⚙️ **组件化零件系统（Part / PartData）**
  所有零件均由数据驱动，结构清晰，易于扩展和维护。

* 🎛 **运行时参数编辑**
  推进器推力、方向、响应特性等参数可在运行时通过 UI 修改。

* 🔁 **构建态 / 仿真态切换**
  明确区分“设计阶段”和“物理仿真阶段”，避免逻辑混乱。

* 🧠 **工程化架构设计**
  强调可读性、可维护性，避免一次性原型式代码膨胀。

---

## 🧱 项目整体设计思路

本项目遵循一个核心原则：**数据、实例、流程分离**。

### 1️⃣ 数据层（Data Layer）

**PartData（Resource）**

* 描述一个零件“是什么”
* 不包含任何 Node 或仿真逻辑
* 可被 UI、构建系统、仿真系统同时使用

典型内容包括：

* 零件类型与 ID
* 对应的场景（PackedScene）
* 可编辑参数定义（范围、默认值、类型）

---

### 2️⃣ 实体层（Runtime Instance Layer）

**Part Instance（Node3D）**

* 真正存在于场景中
* 参与物理仿真
* 只关心自身行为，不关心 UI 和编辑流程

示例：

* 推进器（Thruster）
* 结构件（Hull）
* 传感器（IMU / 深度计等）

---

### 3️⃣ 构建层（Builder / Assembler Layer）

**运行时拼装系统**

* 根据 PartData 创建零件实例
* 管理零件的选择、移动、旋转
* 提供运行时 Gizmo 与参数面板
* 控制 Build / Simulation 状态切换

> 该层只实现“必要的编辑能力”，刻意避免演化成完整编辑器。

## ▶️ How To Use（使用说明）

### 1️⃣ 下载 Godot Engine 4.6

本项目 **仅支持 Godot Engine 4.6**。

1. 访问 Godot 官方网站：
   [https://godotengine.org](https://godotengine.org)
2. 下载 **Godot 4.6 Stable（Standard 版本）**
3. 解压即可使用（Godot 为免安装程序）

> ⚠️ 不建议使用 4.5 或更早版本，API 不完全兼容。

---

### 2️⃣ Clone 项目代码

确保你的电脑已安装 Git，在命令行中执行：

```bash
git clone <项目仓库地址>
```

Clone 完成后，你会得到一个包含 `project.godot` 的项目目录。

---

### 3️⃣ 在 Godot 中打开项目

1. 启动 Godot 4.6
2. 在项目管理器中点击 **Import**
3. 选择项目目录
4. 选中 `project.godot`
5. 点击 **Import & Edit**

项目将自动加载，无需额外配置。

---

### 4️⃣ 运行拼装场景

1. 打开主拼装场景（如 `builder_scene.tscn`）
2. 点击 **Run Current Scene** 或直接运行项目

你将进入运行时拼装界面，可进行零件添加与调整。

---

### 5️⃣ 基本使用流程

1. **添加零件**
   从零件列表中选择推进器或其他组件

2. **选择零件**
   点击场景中的零件实例

3. **调整位置与朝向**
   使用运行时 Gizmo 进行移动或旋转

4. **修改参数**
   在参数面板中调整推进器、传感器等属性

5. **切换到仿真模式**
   锁定结构，启用物理与控制逻辑

---

## 🔁 Build / Simulation 模式说明

| 模式         | 说明                |
| ---------- | ----------------- |
| Build      | 拼装、移动、旋转、参数编辑     |
| Simulation | 启用物理、推进器与传感器，禁止编辑 |

模式切换由统一的管理节点负责。

---

## 🧠 架构设计原则

* 不复刻 Godot 编辑器
* 不让 UI 直接操纵物理状态
* 数据与实例严格分离
* 每个 Part 自治、可替换
* 系统按子模块逐步扩展
